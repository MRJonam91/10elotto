# 10eLotto

Un progetto dedicato alla consultazione delle estrazioni 10eLotto.

## Stato del progetto

Il progetto è in fase di preparazione; l’applicazione e il database non sono ancora presenti in questa repository.

## Dati e fonti

Le estrazioni ogni cinque minuti e quelle legate al Lotto richiedono archivi distinti. Consulta l’[archivio ufficiale](https://www.lotto-italia.it/10-e-lotto/estratti). Uno storico completo riutilizzabile non è ancora incluso.

Le estrazioni sono casuali: frequenze e risultati passati non permettono di prevedere quelli futuri.
