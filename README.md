# 10eLotto

Cartella del progetto 10eLotto per manoj.it. Preparazione dati e analisi; le future funzioni saranno sviluppate separatamente.

Le estrazioni ogni cinque minuti, quelle legate al Lotto e le opzioni richiedono archivi distinti. Fonte ufficiale: https://www.lotto-italia.it/10-e-lotto/estratti.

In `storici/10elotto-legato-lotto.zip` è conservato localmente un DBF di [Lotto Scientifico](https://www.lottoscientifico.com/archivio-download.php), scaricato il 21 novembre 2026: 7.417 righe datate dal 1939 al 20 novembre 2026. Le righe anteriori all'esistenza del gioco non sono estrazioni storiche effettive del 10eLotto. Diritti di ripubblicazione non verificati; il file è escluso dalla repository pubblica. Non include le estrazioni ogni cinque minuti o i dati delle opzioni.

Le estrazioni sono casuali: i dati storici non prevedono risultati futuri.
